# Security policy

## Supported beta builds

Only the current `main` branch and the latest tagged beta release receive
security fixes.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub’s private
security advisory flow for this repository, or contact the DueVinci maintainers
through the security contact listed in the DueVinci project.

Include the affected version, reproduction steps, and impact. Remove account
credentials, access tokens, course documents, and student information from all
reports.

## Privacy boundaries

The extension scans only after the student clicks **Scan current course page**.
It sends only the rows the student approves to DueVinci. It does not collect
grades, submissions, student details, or whole-page HTML.
